# 文档与当前实现差距核对

日期：2026-10-10。范围：`spec/` 原始文档、`app/`、`web/src/`、脚本及测试。原规格未修改。本表按代码路径审阅，未以自动化测试数量推算完成比例。

结论：已有可运行首版，**文档全部 P0 尚未完成**。本次修通 AKShare 原始取数，但 `RAW_FEED_REACHABLE` 不等于 `PERSONAL_RUNTIME_READY`；当前发布状态保留 `DATA_PROVIDER_BLOCKED`。

## 本次已修复，不再列为待实现

- 东方财富 requests 远端断连：默认改为隔离 worker 内的标准 curl 传输，实际两股取数成功。
- 历史 open=0、当前尚未收盘行、集合竞价行使整股拒收：逐行隔离并统计原因；真正坏行仍阻断该股信号。
- 通用错误掩盖问题：传回安全错误码；带错误的股票不计为有效采集数，不生成新信号。
- NTP 刷新后与刷新前时刻比较造成误判：使用测量后的当前时刻验证。
- 报告过度归纳：G08/G09/G10/G11/G12/G13 等组件测试通过仅记 PARTIAL；重新生成测试索引不会覆盖已有实盘测量文件。
- 已写入真实交易日历和 SNTP 见证；未填写未经核验的 provider 资格或股票元数据。
- 重启发现旧服务被 SSE 长连接拖住退出，启动脚本已增加 10 秒优雅退出上限；备份后恢复本机服务，数据库检查为 ok。该次空自选池恢复不能替代有活跃 Episode 的崩溃/去重验收。
- 独立端口实际验证活跃 SSE 连接下 SIGTERM 退出：10.231 秒内完成生命周期清理、释放锁、数据库检查 ok，见 [退出验证](sse-shutdown-check.json)。可用 `scripts/check_shutdown.py` 复测。

## 不应算作 V1 必须缺失

Tushare 在架构中是 optional；QMT 是依账户和平台的后续接入；100 股需扩容验证。当前只接 AKShare/东财，新浪仅做探测。自动交易、收益预测、买入评级、SaaS 多用户权限、浏览器关闭后推送均不属于本版目标。

## 验证与推进顺序

本次后端完整测试 88 项通过，其中新增真实适配问题回归、混合坏数据禁发和证据文件防覆盖。原有浏览器 7 项及规格 8 项报告保留；这不意味着上述缺口已补齐。
